### 🧑‍💻 About me

- 🖥️ Building a Go system that runs a fleet of Windows PCs: self-updating agents, signed releases, canary rollouts and a React dashboard
- 🔐 Building **counter-tls**, a Go HTTP client that looks exactly like a real browser on the wire
  - Matches Chrome (up to 154), Edge and Brave over HTTP/1.1, HTTP/2 and HTTP/3 (QUIC): the TLS handshake, HTTP/2 settings and priorities, header order and casing
  - Every browser version is checked against packet captures of the real browser
- 🏠 Running a homelab on Proxmox, with Cloudflare Tunnels and a stack of mini PCs
- 🛡️ Goal: move to the defense side and build bot detection and anti-fraud systems
